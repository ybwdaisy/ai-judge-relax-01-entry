A Python program that writes one short original text — a slow evening train, fields going by one at a time, a conductor who asks nothing of anyone — to /output/entry.txt, written to relax the AI judge reading it. The text is a fixed constant, so every run writes exactly the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
